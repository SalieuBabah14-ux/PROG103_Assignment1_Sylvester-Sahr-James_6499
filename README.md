Rationale 1: Need for the System
The Student Record Management Terminal System was developed to address the challenges of managing student data manually in many schools and institutions. Traditional methods such as paper records are often inefficient, prone to errors, and difficult to maintain. Important information like student scores and grades can easily be lost or miscalculated.
This system provides a simple digital solution that allows users to store, process, and retrieve student records efficiently. By automating tasks such as grade calculation and record searching, the system reduces human error and saves time. It is especially useful in environments with limited access to advanced technology, as it runs in a basic terminal without requiring a graphical interface.
 
Rationale 2: Choice of Structured Programming Approach
The system is designed using structured programming principles to ensure clarity, simplicity, and maintainability. Structured programming organizes code into logical sections using functions, loops, and decision-making statements. This makes the program easier to understand, debug, and modify.
Functions are used to break the program into smaller, manageable parts such as adding students, calculating grades, and displaying records. Loops allow the program to handle multiple inputs efficiently, while conditional statements control the program’s logic and decision-making process.
Additionally, input validation is used instead of exception handling to prevent errors before they occur. This approach improves the reliability of the system and demonstrates strong problem-solving skills. Overall, structured programming ensures that the system is well-organized, efficient, and scalable for future improvements.
